# October 11 beta sprint

Implemented matching protocol and substance sheets with separate 44-point Close controls, vertical date fields, and keyboard handling. Removed repetitive Other tracked substances from Today.

Timeline supports editing recorded amount, local date/time and site, plus Undo. Unit and original container identity stay fixed. Correcting an amount applies the difference to stock atomically; Undo marks the entry voided, restores stock once and retains an append-only owner-scoped revision record. Exports include revisions. Account deletion cascades them. Capacity conflicts after a manual stock correction must be reconciled before Undo can proceed.

Today distinguishes not-yet-recorded, completed and skipped entries. Skip never consumes stock. Completed takes precedence if both exist on the same day. Undo removes the latest entry, not every entry for a substance. Paused items have a compact Protocol link; off-days do not contribute scheduled occurrences. Existing reminder scheduling is unchanged.

Live migration: 20261012024437_log_corrections_and_skips.sql. SQL regression tests run on random fixture accounts in a rolled-back transaction, before and after migration application. Covered amount edits, backdating, stock rollback on insufficient inventory, stale revisions, nonfinite amounts, cross-account/unconfirmed denial, repeat Undo, immutable audit writes and idempotent skipped records. Seven unit tests and TypeScript pass; native JS exports checked separately.

Device acceptance still needed: matching sheets, Close touch targets, keyboard reachability, amount correction with stock updates, date/time edits, Skip and Undo, logout, export and account deletion using a disposable account. Do not mark the Asana tasks complete before device acceptance.

Remaining limits: editing/Undo/Skip require connectivity; legacy offline timestamps and sync visibility belong to the next sprint. Multiple-times-per-day occurrence tracking is not added. Older clients can show voided entries until updated. Existing Supabase advisor warnings remain for intentionally privileged stock correction and disabled leaked-password protection.

## Visual refinement

Shared PageHeader and SheetHeader unify hierarchy and accessible Close controls. Primary actions use sentence case, larger label text and consistent weight. Secondary labels and backgrounds are quieter, inventory wording is plain, and decorative navigation indices/footer slogans are removed. Today retains its summary, weekly record and useful schedule/supply details while removing the duplicate daily progress panel. Shared forms were inspected in a local browser preview; iPhone rendering and large-text acceptance remain necessary.
